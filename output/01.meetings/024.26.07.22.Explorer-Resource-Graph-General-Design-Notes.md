## Design Vision

Keep Explorer View's proven metadata-table foundation, then layer on conversational querying, AI-generated queries, and AI-driven relationship visualization that helps users understand dependencies, blast radius, and resource context.

---

## Features to Adopt into Explorer View (inspired by Graph UI Demo)

- **LLM manipulation of the UI** - Conversational Query featurette (bottom agent feature to engage through)
- **Natural language as the query generation trigger**
- **Context-aware graph manipulation** - ability to dynamically focus, filter, highlight, and navigate graph data based on a user request
  - Resource relationships / dependencies / metadata connections
  - Blast radius potential for changes
- **Table + graph dual experience** - table view should be more prominent. The model is:
  1. Explore metadata in a table
  2. Drill in and query data
  3. Use the graph/visualization to provide context and understanding
- **Metadata table as primary view** with graph visualization as secondary supplement

---

## Features to Leave Behind

- Shipping the visualization as a standalone product
- Making the visualization a primary experience
- Adopting the D3 codebase (security risk)
- Enriching the graph visualization too deeply (match the depth of Explorer View as it is now; do not over-invest in graph complexity)
